# tq2ka.ru

Статичный сайт исполнителя tq2ka. Без сборки: чистые HTML, CSS и JS, хостинг на GitHub Pages.

## Что где лежит

| Путь | Что это |
|---|---|
| `index.html` | вся страница: шапка, первый экран, лента, релизы, звучание, цитата, подвал |
| `css/style.css` | стили; палитра светлой и тёмной темы в начале файла |
| `css/fonts.css`, `fonts/` | шрифты Cormorant Garamond, Onest, Caveat — хранятся локально |
| `js/main.js` | тема, шапка, меню, волна, блики на фото, искры за курсором, плеер, пасхалка |
| `js/sparkles.js` | координаты бликов на аватарке (генерирует `tools/prep.py`) |
| `img/` | аватарка, обложки, иконки, og-картинка для превью ссылок |
| `favicon*.png`, `favicon.ico`, `site.webmanifest` | иконка сайта (из `tools/src-icon.png`, скрипт `tools/icons.py`) |
| `audio/` | сюда класть mp3, если нужен встроенный плеер |
| `tools/` | исходники картинок и скрипты подготовки и проверки |

## Тема

По умолчанию сайт берёт тему из системы (светлая или тёмная). Кнопка с солнцем и луной в шапке
переключает вручную; если выбрать ту же тему, что в системе, сайт снова следует системе.

## Пластинка в первом экране

CD рядом с фото медленно вращается. Если схватить его мышкой или пальцем и крутить, играет
`audio/almaz.mp3` («я алмазный человек»). Один оборот в секунду — обычная скорость и тон, это максимум ×1;
медленнее — ниже и тягучее, назад — задом наперёд. Отпущенная пластинка замедляется по инерции.
Пока играет звук, от пластинки влево бежит волна; в тишине её нет.
С клавиатуры: Tab до пластинки, стрелки влево/вправо крутят, Enter — толчок.

Звук читает `js/turntable-worklet.js` (AudioWorklet). Другой трек — поменять `data-src` у `.badge` в `index.html`.

## Как добавить трек в плеер

1. Положи файл в `audio/`, например `audio/ytsuken.mp3`.
2. В `index.html` у нужного релиза впиши `data-audio="audio/ytsuken.mp3"`.

На обложке появится кнопка воспроизведения. Пока трек играет, CD выезжает из-за обложки и крутится.

## Как поставить точную ссылку на релиз

Сейчас «Слушать» у каждого релиза ведёт на поиск по названию в Яндекс Музыке.
Когда будет ссылка на сам альбом (`https://music.yandex.ru/album/…`), замени ею адрес
в карточке релиза, в блоке «Звучание» и в списке в подвале.

## Новая иконка

Замени `tools/src-icon.png` (квадрат, фигура на прозрачном фоне) и запусти `python tools/icons.py`.

## Новая аватарка или обложки

Замени файлы `tools/src-*.png` и запусти из корня проекта:

```
python tools/prep.py
```

Скрипт пересоберёт картинки в `img/` и заново найдёт блики на фигуре (`js/sparkles.js`).

## Пасхалка

Набери на клавиатуре `й ц у к е н` (или `q w e r t y`): страница прокрутится к релизу «йцукен»,
и диск вылетит золотым.

## Домен tq2ka.ru → GitHub Pages

Домен стоит на бесплатных DNS-серверах reg.ru (`ns1.reg.ru`, `ns2.reg.ru`), хостинг reg.ru не нужен.
Записи правятся в личном кабинете: «Домены» → tq2ka.ru → «DNS-серверы и управление зоной» → «Ресурсные записи».

| Тип | Имя | Значение |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| CNAME | `www` | `cvapta.github.io.` |

В репозитории: Settings → Pages → Custom domain `tq2ka.ru` и галочка «Enforce HTTPS».
Файл `CNAME` в корне GitHub создаёт сам.

## Локальный просмотр

```
python -m http.server 8770
```

и открыть http://localhost:8770.
